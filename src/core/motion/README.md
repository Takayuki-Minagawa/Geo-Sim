# 地震動計算コア

## 入力と検証

- 加速度単位は `g`、`gal`、`m/s2` のいずれかとし、内部では `m/s2` に統一する。`1 g = 9.80665 m/s2`、`1 gal = 0.01 m/s2`。
- 時刻と加速度は同じ点数、2点以上、既定100万点以下、すべて有限値とする。
- 時刻は厳密な昇順かつ等時間刻みとする。等間隔判定には相対許容差 `1e-6` と絶対許容差 `1e-10 s` の大きい方を使う。

## 基線補正と積分

積分は台形則を使用し、初速度・初期変位の既定値を0とする。基線補正は呼出側が明示的に次から選ぶ。

- `none`: 補正しない。既に補正済みの波形や解析解との比較用。
- `mean`（既定）: 台形積分で求めた時間重み付き平均加速度を除く。初速度0なら終端速度が数値誤差内で0になる。
- `linear`: 加速度の最小二乗一次トレンドを除き、端点重みの差による残余平均も除く。

高域・低域フィルタや強制的な終端変位補正は行わない。このためPGDは基線補正方法に敏感であり、利用者は採用方法を結果とともに保存する必要がある。PGA・PGV・PGDおよび応答スペクトルは、同じ補正後加速度から算出する。

## 弾性応答スペクトル

単位質量の1自由度系

`ü + 2 h omega u̇ + omega^2 u = -ag`

をNewmark平均加速度法（`beta=1/4`、`gamma=1/2`）で逐次積分する。既定減衰比は5%。入力点間の加速度は線形補間し、内部刻みを原則として固有周期の1/10以下とする。平均加速度法は線形系で無条件安定だが、入力時間刻みが対象周期の1/10を超える場合、失われた高周波成分は補間では復元できないため警告する。

- `Sd`: 相対変位 `|u|` の最大値
- `Sv`: 相対速度 `|u̇|` の最大値（擬似速度ではない）
- `Sa`: 質点の真の絶対加速度 `|ü + ag|` の最大値（`omega^2 Sd` ではない）
- `T=0`: 剛体極限として `Sa=PGA`、`Sv=Sd=0`

このMVPは地震動そのものの積分と線形1自由度応答を扱い、一次元等価線形地盤応答解析やDYNES3D相当の多層地盤伝達解析は含まない。
