# アーキテクチャと計算仕様

- 対象版: 0.1.0
- 作成日: 2026-07-19
- 状態: 開発・検証版（専門家レビュー待ち）

## 構成

アプリはViteでビルドするReact + TypeScriptの静的Webアプリである。案件データと計算配列はブラウザ内だけで処理し、実行時API、Excel、VBA、旧外部解析プログラムは使用しない。

```text
ファイル選択
  → JSON / CSV / 旧XLS入力アダプタ
  → 単位付きドメインモデル
  → Web Worker
       ├─ Vs・Tg・Gs・Sa/Sv/Sd
       ├─ FL・Dcy・PL
       └─ PGA/PGV/PGD・弾性応答スペクトル
  → 画面 / 印刷 / JSON / CSV
```

Workerと直接実行は同じ純粋関数を呼び出す。時刻歴配列は `Float64Array` の `ArrayBuffer` をtransferableとして渡す。

## 入出力

| 形式 | 用途 | 制約 |
|---|---|---|
| `.jiban.json` | 案件正本 | JSON Schema 1.0.0、10 MiB以下、Ajv検証 |
| `layers.csv` | 地層入出力 | UTF-8 BOM、500層以下、式注入対策 |
| `n-values.csv` | N値入出力 | UTF-8 BOM、10,000行以下、式注入対策 |
| `motion.csv` | 時刻歴入力 | 時刻(s)+加速度、2〜1,000,000点、単位明示 |
| `.xls` / `.xlsx` | 旧資産の入力値抽出 | 20 MiB以下、数式・VBA・外部リンクを実行せず結果に採用しない |

内部単位は長さ m、速度 m/s、加速度 m/s²、密度 kg/m³、応力 Paである。旧重力単位は液状化互換式内の明示した変換層だけで使用する。

## Vsと弾性地盤周期

- N値平均は層上端を除外、層下端を含む。
- 直接入力Vsがある場合は推定値より優先する。
- Vs係数表は `regulatory` と `legacy-sheet` を別IDで管理する。
- 弾性地盤周期は層厚とVsによる四分の一波長近似から計算する。

## 地盤増幅 Gs

実装モードは次の5つである。

| モードID | 位置付け |
|---|---|
| `damage-simplified` | 損傷限界・略算 |
| `safety-simplified` | 安全限界・略算 |
| `safety-precise` | 安全限界・現行精算 |
| `legacy-damage-precise` | 旧シート照合・損傷限界 |
| `legacy-safety-precise` | 旧シート照合・安全限界 |

略算は地盤種別と根拠文言を必須とし、0.576 / 0.64 / 0.864 / 1.152 sの分岐を明示的に実装する。標準加速度応答スペクトル `S0(T)`、地域係数 `Z`、`Gs(T)` から地表 `Sa`を求め、角振動数から `Sv`、`Sd` を導く。

精算はせん断棒モデルの対称一般化固有値問題をJacobi法で解き、非線形曲線を反復する。相対誤差、絶対誤差、最大反復回数、層別ひずみ・剛性比・減衰を履歴に保存する。現行精算では旧シートの0.8係数を使用しない。旧モードは別モジュールで計算し、法適合値でない旨を常時表示する。

## 液状化

- 評価ケースは150 gal / M7.0と350 gal / M7.5。
- `nf`、`ganmacy`、FL、Dcy、PLは旧シート由来のスクリーニング法として別IDで出力する。
- 地下水位、改良深さ、層境界、20 m境界で分割した同一の正規化層をDcyとPLが使用する。
- 各層の対象可否と理由、N、Na、L、R、FL、循環せん断ひずみ、Dcy・PL寄与を出力する。
- AIJ由来の表・係数は利用条件と版の専門家確認が未了である。

## 時刻歴

加速度を `g` / `gal` / `m/s²` からSIへ変換し、有限値、単調時刻、等時間刻みを検査する。平均または一次傾向の基線補正後、台形積分でPGA / PGV / PGDを求める。5%減衰弾性応答スペクトルはNewmark平均加速度法で `Sa` / `Sv` / `Sd` を計算する。

## 安全上の境界

本版は一次元等価線形地盤応答、建物―地盤相互作用 `β`、BORING/XML、支持力計算を含まない。最終設計判断に使用する前に、入力の出典、適用条件、地盤の二次元性、液状化による支障を有資格者が確認する。
