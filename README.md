# Geo-Sim — 地盤解析Webアプリ

地盤データの整理と、地盤増幅・液状化・時刻歴応答の比較検討を支援する静的Webアプリです。計算はブラウザ内で実行し、案件データはファイルのアップロード／ダウンロードで受け渡します。

- 公開版: [https://takayuki-minagawa.github.io/Geo-Sim/](https://takayuki-minagawa.github.io/Geo-Sim/)
- 既定表示: 日本語・ライトモード
- 表示切替: 日本語／英語、ライト／ダーク
- 画面内の「簡易マニュアル」から基本操作と注意事項を確認できます

## 主な機能

- 旧 `.xls` から入力セルを抽出（VBA・数式・外部リンクを実行せず、数式キャッシュや保存済み計算結果を解析入力として採用しません）
- `.jiban.json`、地層CSV、N値CSV、時刻歴CSVによるデータ交換
- 入力条件に基づくVs推定、弾性地盤周期、Gsの略算・精算・旧シート比較
- 設定された告示関連の係数・スペクトル定義に基づく地表 `Sa` / `Sv` / `Sd` の確認
- 150 gal / M7.0および350 gal / M7.5条件のFL・Dcy・PL参考スクリーニング
- PGA / PGV / PGDおよび5%減衰弾性応答スペクトル
- Web Workerによる解析、進捗・取消、SVGグラフ、A4印刷、JSON/CSV出力

画面上の「安全限界」「損傷限界」「精算」等は、実装された計算モードを識別する名称です。表示された名称だけで、個別案件への法的適合性、適用可能性または設計上の妥当性が確認されたことにはなりません。

## 利用上の重要な注意

本アプリは、技術者による確認作業を支援するための開発・検証用ツールです。次の点を理解したうえで使用してください。

- 結果は、入力値、地盤モデル、採用した係数、計算上の仮定および実装された適用範囲に依存します。
- 本アプリの出力だけを根拠として、設計、施工、法適合、地盤・液状化による支障または安全性の最終判断を行わないでください。
- 実案件への利用前に、有資格者・専門技術者が入力、単位、地盤モデル、適用条件、収束、出力および根拠資料を確認してください。
- 法令、告示、技術基準、指針および係数表は改定される場合があります。必ず利用時点の原典と適用条件を確認してください。
- 液状化機能には、旧シート由来の計算手順を整理した参考スクリーニングが含まれます。詳細調査や正式な判定を代替するものではありません。
- 旧ブックとの比較モードは再現性確認のための参考機能であり、法適合値や設計値として単独で使用しないでください。

本アプリのコードには、読み込んだ案件ファイルを外部サービスへ送信する処理はありません。ただし、公開サイトへのアクセス時に通常発生するHTTP通信、利用者のブラウザ拡張、端末・ネットワーク環境による通信まで保証するものではありません。機密情報を扱う場合は、組織の情報管理ルールに従い、必要に応じてローカル環境で実行してください。

## 基本操作

1. 初期モデルを編集するか、「ファイルを開く」から案件ファイルを読み込みます。
2. 案件、地盤種別、地下水位、地層、N値、密度、Vs、工学的基盤および各値の出典を確認します。
3. 必要な計算モードと入力加速度単位を選択して解析を実行します。
4. 警告、適用条件、収束状態、地盤増幅、液状化、時刻歴およびレポートを確認します。
5. 必要に応じて案件JSON、結果JSON、CSVまたはPDFを保存します。

入力を変更すると、以前の解析結果は失効します。変更後は再解析してください。

## ローカルでの起動

Node.js 22以上を使用します。

```bash
npm ci
npm run dev
```

ブラウザに表示されたローカルURLを開きます。案件ファイルを読み込まない場合は、動作確認用の初期モデルが表示されます。

## 検証と静的ビルド

```bash
npm run check
npm run test:e2e
```

`npm run check` は型検査、ESLint、単体テスト、本番ビルドを実行します。`npm run test:e2e` はビルド済みアプリをChromium、Firefox、WebKitで確認します。配信物は `dist/` に生成されます。
