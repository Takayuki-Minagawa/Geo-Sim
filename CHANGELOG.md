# Changelog

## 0.1.0 - 2026-07-19

- Add a browser-only static ground analysis application with seven task screens.
- Add legacy XLS input-only conversion plus JSON and CSV exchange.
- Add Vs/Tg, simplified and precise Gs, surface Sa/Sv/Sd, liquefaction screening,
  motion integration and a 5% damped elastic response spectrum.
- Add Web Worker execution, progress/cancel, charts, A4 print output and detailed
  JSON/CSV results.
- Add strict type checks, linting, unit tests, three-browser Playwright tests,
  CSP, CI and GitHub Pages workflows.
- Mark legal-basis and expert-review items as pending; this release is a
  development/verification build and does not claim regulatory compliance.
